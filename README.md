# Chrome Web Store assets

Public listing material for three Chrome extensions.

This repository is public for one reason: the Chrome Web Store requires each extension's privacy
policy at a URL anyone can open. The extensions' source code lives in a separate, private
repository — nothing here is code.

---

## Bulk Chat Delete for ChatGPT

Deletes, archives or unarchives ChatGPT conversations in bulk, paced to stay under ChatGPT's
rate limits. Files are at the root of this repository:

| File | What it is |
|---|---|
| [PRIVACY.md](PRIVACY.md) | **The privacy policy** submitted to the Chrome Web Store. |
| [START-HERE.md](START-HERE.md) | Short step-by-step for publishing the listing. |
| [PUBLISHING.md](PUBLISHING.md) | The same process with the reasoning and edge cases. |
| [LISTING.md](LISTING.md) | Listing copy, permission justifications, data-usage answers. |
| [PRIVACY-TAB.txt](PRIVACY-TAB.txt) | The Privacy-tab answers as plain text, ready to paste. |
| [screenshots/](screenshots) | Five 1280×800 store screenshots. |
| [promo/](promo) | Small (440×280) and marquee (1400×560) promo tiles. |

*Not affiliated with, endorsed by, or sponsored by OpenAI.*
