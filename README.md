# Chrome Web Store assets — Bulk Chat Delete for ChatGPT

Public listing material for the Chrome extension **Bulk Chat Delete for ChatGPT**.

This repository is public for one reason: the Chrome Web Store requires a privacy policy at a URL
that anyone can open. The extension's source lives in a separate, private repository.

| File | What it is |
|---|---|
| [PRIVACY.md](PRIVACY.md) | **The privacy policy.** This is the URL submitted to the Chrome Web Store. |

| [PUBLISHING.md](PUBLISHING.md) | The same process with the reasoning and edge cases. |
| [LISTING.md](LISTING.md) | Listing copy, permission justifications, data-usage answers. |
| [screenshots/](screenshots) | The five 1280×800 store screenshots. |

### About the extension

Bulk Chat Delete for ChatGPT deletes, archives or unarchives ChatGPT conversations in bulk, paced
to stay under ChatGPT's undocumented rate limits. Everything runs in the browser — no servers, no
analytics, and nothing is transmitted anywhere except chatgpt.com. See
[PRIVACY.md](PRIVACY.md) for the detail.

The screenshots use generated sample data, not real conversations.
